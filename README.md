# Раскраска для Procreate

Веб-приложение (Nuxt 4 / Vue 3, только фронтенд), которое превращает PNG / JPG / WEBP в набор для раскрашивания в Procreate:

- **`.procreate`** со слоями (сверху вниз):
  - **Контур** — чёрные линии, режим «Умножение», закреплён;
  - **Раскраска** — пустой слой, выбран при открытии;
  - **Референс** — раскрашенная версия с цветами палитры (скрыт, включите для сравнения);
  - **Белый** — белая подложка, закреплён.
- **`.swatches`** — палитра Procreate из цветов референса (2–30 цветов).

Все вычисления идут в браузере (Web Worker), результаты живут только в открытой вкладке.

## Контур

- **Авто** — определяет, есть ли на картинке тёмный лайнарт.
- **Взять из картинки** — тёмные тонкие линии становятся слоем «Контур» (с сохранением сглаживания), их цвет не попадает в палитру; толстые тёмные заливки остаются цветом.
- **Построить по границам цветов** — для фото и картинок без обводки: после квантования линии рисуются по границам цветовых областей.

## Разработка

```bash
npm install
npm run dev
npm run verify   # синтетический тест конвейера и формата файлов (нужен macOS plutil)
```

Деплой — GitHub Actions → GitHub Pages (`.github/workflows/pages.yml`).

## Формат

`.procreate` — zip с `Document.archive` (NSKeyedArchiver bplist, `SilicaDocument`), `QuickLook/Thumbnail.png` и тайлами 256×256 `{col}~{row}.chunk` (LZO1X, premultiplied RGBA, строки снизу вверх). Структура повторяет реальные файлы Procreate; описание формата — [topsd/procreate-format](https://github.com/topsd/procreate-format). Цветовой профиль — sRGB ([Compact-ICC-Profiles](https://github.com/saucecontrol/Compact-ICC-Profiles), CC0).
